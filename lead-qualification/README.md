# AI Lead Qualification & Routing System
This system automatically qualifies, prioritizes, and routes leads — so high-value opportunities are never missed.

## Problem

Most businesses don’t have a lead problem — they have a lead handling problem.

Leads are coming in, but nothing is managing them properly.
- No clear prioritization
- Slow or inconsistent responses
- High-value leads get missed or delayed


---

## Solution

This system automatically captures, analyzes, and routes leads using AI.

---

## How it works

1. A new lead is added to Google Sheets
2. The system filters valid entries
3. AI analyzes the lead and extracts:
   - Priority (Hot / Warm / Cold)
   - Budget
   - Urgency
   - Summary
4. Data is structured and stored
5. High-priority leads trigger instant alerts (Email + Telegram)
6. Lower-priority leads follow a different response path

---

## Tools used

- n8n
- Google Sheets
- Gmail
- Telegram
- AI (Groq / LLM)
- JavaScript (data formatting)

---



## Result

- Leads are automatically prioritized
- High-value leads are handled instantly
